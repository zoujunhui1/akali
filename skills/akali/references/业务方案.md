# 业务方案

## 目标
把 ELLLO 里学过的课程放进手机，离线反复听，路上也能听。

## 使用者与设备
- 只有用户自己，不上架。
- 一加 15T，直接真机安装。

## 内容
- 来源：ELLLO 视频课（B2、C1 级别），每课约 1 分钟，mp3 平均约 1.3 MB。
- 现有内容：电脑上 `~/Documents/english study/elllo/`，68 课（B2-001~050、C1-006~050 中的部分）。
- 现有每课一个文件夹：

```
B2-036-Eulices-Dream-Job/
  B2-036-Eulices-Dream-Job.mp3     命名不统一，如有的只叫 C1-006.mp3
  transcript.txt                   纯文本，按段落，无时间戳
```

- 电脑上的 `elllo/` 只用于首次导入，不进 git。其中 `B2-044` 多了 mp4/srt/vtt（约 30 MB），不需要。

## 添加新内容（已改：不在 app 里添加。在 Mac 的 akali studio 页面粘贴链接处理，传到后端，手机同步；见 架构方案.md）
在 app 里粘贴 ELLLO 课程链接，由 app 完成：抓页面 → 下载主音频 → 提取文稿 → 存私有目录 → 加入列表。

- 所有音频完整下载保存。体积：每天一课约 475 MB/年。存储不无限增长和全部离线无法兼顾，所以提供清除功能。
- 依赖 ELLLO 页面结构，改版后解析会失效，需要更新 app。

## 首次导入已有 68 课（已完成：由 `mac/upload_existing.py` 传到后端；app 里的文件夹导入已删除）
1. 一次性脚本给每个课程文件夹补 `url.txt`（ELLLO 原链接），逐个访问验证，对不上的单独列出。
2. USB 把 `elllo/` 拷到手机，app 里点“导入”，音频和文稿复制进私有目录。
3. 有 `url.txt` 的课程，清除音频后可重新下载。

## 功能范围

### 第一版（V1）
| 功能 | 说明 |
|---|---|
| 添加课程 | 粘贴 ELLLO 链接，app 下载音频并提取文稿 |
| 清除音频 | 只删本地 mp3，保留条目和文稿，列表标为“未下载”，可重新下载；支持多选批量 |
| 彻底删除 | 整课删除（音频、文稿、记录） |
| 存储占用 | 设置页显示课程数和已占用空间 |
| 课程列表 | 默认按编号排序，显示标题 |
| 播放控制 | 播放/暂停、拖动进度 |
| 播放模式 | 单课循环 / 列表循环 / 顺序播放 / 随机，一个按钮循环切换，默认列表循环；队列为列表中已下载的课，从点击的那课开始 |
| 课间停顿 | 每课播完停 2 秒再播下一课 |
| 排序 | 编号升序（默认）/ 编号降序 / 添加时间（最新在前）；连播顺序跟随当前排序 |
| 调速 | 0.75x / 1x |
| 后台播放 | 前台服务 + 媒体通知，锁屏和耳机按键可控 |
| 文稿显示 | 播放页显示整段文稿，可切换隐藏/显示（先听后看） |

### 后续
- 单句循环 / 逐句同步（需要给文稿补时间戳：强制对齐或语音识别，工作量大，与“不用电脑”的约束有冲突，到时再定）
- 学习记录：播放次数、收藏、掌握程度
- 飞书生词关联（飞书表：702 行生词，按“视频”字段对应课程）

### 不做
- 账号、云同步、云服务器
- 电脑端脚本（除一次性补 url.txt）、Syncthing
- 边播边缓存

## 非功能要求
- 播放完全离线；只有添加课程时联网。
- 一加电池管理激进：必须用前台服务，并引导用户把电池设为“不受限制”。
- Android 13+ 需要通知权限。
- targetSdk 36（Android 16），minSdk 30（Android 11），不做老机型兼容。
