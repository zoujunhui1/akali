# akali

Self-use English listening app (ELLLO lessons), in three parts:

- `android/` — the phone app (Kotlin + Compose)
- `server/` — the backend (Go + Gin + MySQL)
- `mac/` — local tools on the Mac (akali studio: fetch lessons, Whisper timestamps, Feishu vocab, upload)

Plans and notes: `skills/akali/`.
